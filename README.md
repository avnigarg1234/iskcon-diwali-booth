# ISKCON Diwali Booth Website

A single-page, mobile-first website for visitors who scan a QR code at the Diwali booth.

- `index.html` is the whole site (no build step, no dependencies).
- Contact number: (972) 768-3436. To change it, search `19727683436` and `(972) 768-3436` in `index.html` and replace every match.
