# Bhakti Vriksha Diwali Booth Website

A single-page, mobile-first website for visitors who scan a QR code at the Diwali booth.

## Files
- `index.html`: the whole site (no build step, no dependencies)
- `logo.png`, `logo-white.png`, `favicon.png`: the lotus brand symbol (all three must stay next to `index.html`)

## Change the contact number
Search `19727683436` and `(972) 768-3436` in `index.html` and replace every match.

## Deploy (Render Static Site)
- Build Command: leave blank
- Publish Directory: `.`
